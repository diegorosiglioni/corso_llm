Prompt per la sessione dopo l'integrazione di `auto-claude` in `dev` (Task 16 del piano delle correzioni). Non servono LM Studio né Docker per il push; servono per le prove reali di un lavoro nuovo.
Il prompt da incollare in Claude Code, dalla radice della repository, è tutto ciò che segue la riga di trattini.
------------------------------------------------------------------------------------------

Leggi il CLAUDE.md, poi PROGRESS.md: prima «Stato attuale», poi le sezioni F4, F5 e F6 della «Revisione e integrazione di `auto-claude`». Controlla lo stato: branch corrente (atteso `dev`), `git status` pulito, `dev` allo stesso commit di `auto-claude`, e confronta `dev` con `origin/dev` e `main` con `origin/main` (`git fetch`, poi `git log --oneline origin/dev..dev` e `git log --oneline main..dev`).

1. Push: fallo solo se te lo chiedo in questa sessione, per intero come da CLAUDE.md (`git push origin dev`, `git push origin dev:main`, `git fetch origin main:main`). Se l'avanzamento rapido di `main` viene rifiutato, fermati e chiedimi: niente `--force`, niente merge automatici. Dopo il push chiedimi se cancellare o tenere il branch `auto-claude`.
